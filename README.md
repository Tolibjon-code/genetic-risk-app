# 🧬 Генетик Синдромлар Хавф Бахолаш Дастури

## Tavsif
Бу дастур хомиладор аёлларда генетик касалликлар хавфини бахолаш учун ишлаб чиқилган. DELFIA Revvity реагентлари асосида ишлайди.

## Ишлатиш учун
1. Скрининг турини танланг (биринчи ёки иккиламчи)
2. Бемор маълумотларини киритинг
3. Лаборатория параметрларини киритинг
4. «ГЕНЕТИК ХАВФЛАРНИ ҲИСОБЛАШ» тугмасини босинг

## Технологиялар
- Python 3.9+
- Streamlit
- Plotly
- Pandas

## Жойлаштириш
Дастур Streamlit Cloud орқали жойлаштирилган.
